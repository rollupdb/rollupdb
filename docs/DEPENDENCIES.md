# Dependency decision

The direct runtime dependencies are modernc.org/sqlite v1.60.1 and github.com/apache/datasketches-go v0.2.0, pinned in go.mod and go.sum. SQLite provides transactions without CGo; its libc requirement remains v1.77.1. DataSketches supplies the generic float64 KLL implementation, numeric serialization, update and merge logic. RollupDB owns the configuration contract, bounded envelope validation, bucket lifecycle and query availability.

The graph includes modernc.org/libc, memory and mathutil, golang.org/x/sys, and small supporting modules. This is more code than a bespoke in-memory aggregate map, but replaces a substantial persistence and recovery implementation. Dependency installation and initial compilation require time and network access; no dependency downloads are required by a built executable.

The SQLite driver has its own license and third-party notices. DataSketches Go v0.2.0 is an Apache Software Foundation release under Apache License 2.0, with its license and original notice retained in third_party/datasketches. compactCapacity in kll_format.go adapts the pinned serializer's capacity calculations under that license so malformed payloads can be rejected before its deserializer allocates buffers. RollupDB itself is also under the Apache License 2.0. Every release archive carries LICENSE, NOTICE and a THIRD_PARTY_LICENSES.md with the full license text of each module compiled into the command, generated by scripts/third-party-licenses.sh.

The DataSketches release, API, source implementation and license were checked for this session. Its first supported RollupDB codec fixes M=8 and permits K from 64 through 4096. Only equal-K merges are accepted. Upstream can merge some different K settings, but RollupDB deliberately refuses that path until a compatible format policy and resulting error bound are supported. Compaction is randomized; no global PRNG reseeding or private test switches are used. The full DataSketches module implements many sketch families, but this engine imports only common float64 serialization and KLL. A small murmur3 transitive dependency is added through the common package.
