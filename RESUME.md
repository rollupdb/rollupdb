## Current implementation

The Go library exposes Create, Open, Migrate, Close, Info, CreateStream, Stream, Ingest, Advance, Query, Status and Snapshot. WithClock supplies explicit replay/test time. The CLI supports init, migrate, inspect, create-stream, stream, stats, ingest, advance, query, snapshot and help, using bounded strict JSON files. NDJSON and HTTP are not implemented. Reads and ingestion do not implicitly run retention. One owner process and a local filesystem are the support contract.

Format revision 4 adds retention_frontiers to the revision-3 exact/runtime/sketch schema. Migrate upgrades revision 1, 2 or 3 to 4 in one transaction, preserving identity, definitions, exact state, serialized sketches and runtime counters/times. Open never silently upgrades. Missing sketches are not backfilled. Definition version 1 is immutable; creating another version or editing a schema is not supported.

Exact statistics use checked int64 count, compensated sum, extrema and Welford/Chan variance state. Public average is compensated sum/count. Ingest accepts 1..10000 observations per batch, uses canonical bounded dimension tuples, deterministic group admission, one sampled clock, a persisted nondecreasing watermark, per-observation outcomes and transactional lifetime counters. Rejected observations update neither exact nor sketch state. Retrying is new input; there is no deduplication. No raw-event table exists.

Quantiles use Apache DataSketches Go v0.2.0 generic float64 KLL. SketchConfig is explicit: algorithm=kll_float64, encoding_version=1, M=8, K in [64,4096]. Only equal configurations merge. The 48-byte RDKL envelope records codec/type/K/M/length/SHA-256; kll_format.go validates bounded native layout/counts/extrema before the pinned decoder. Unknown, missing or corrupt configured state fails before mutation. The adapted compactCapacity validator retains Apache attribution and third_party/datasketches notices. Do not change dependency/codec assumptions without compatibility review.

KLL compaction is randomized. A query on one persisted bucket uses that decoded sketch directly and remains identical across restart/snapshot/copy. Multi-bucket query merges can recompact and vary in point answers while exact state remains unchanged. Do not reseed global PRNGs or use private deterministic hooks. K=200's approximately 0.0132947575 normalized-rank model is an empirical 99% maximum-error fit, not a deterministic bound or relative value-error guarantee. Inclusive nearest-rank rounding is documented in docs/SKETCHES.md.

## Retention and availability

Advance(ctx,stream) samples the clock once, clamps to the persisted watermark, and processes tiers from finest upward. A whole parent [p,e) is eligible only when watermark-e >= max(source retain, source grace), and higher-tier promotion additionally requires lower-tier completion through e. Fine detail may live up to an extra parent width. Only whole parents are published; no partially accumulated target overlaps children. Per-parent groups are merged individually with bounded application working state, closing read cursors before writes. Existing target insertion is refused rather than remerged. Actual populated intervals are visited; empty years advance by ranges.

A complete persisted frontier set covers the contiguous prefix from effective_at for every tier, including empty intervals. For nonfinal tiers through_exclusive means promoted through; for the final tier it means expired through. A forever final tier remains at effective_at. New/migrated streams with no rows default every frontier to effective_at until the first Advance persists the full set. A partially present, misaligned, out-of-range or nonmonotone set is refused. Final finite expiry removes state and keys with no remaining references at any tier. Forever retention preserves final state and can preserve keys indefinitely.

Parent insertion, child deletion, frontiers, final expiry, key reclamation and watermark commit in one transaction. An error returns zero AdvanceResult and rolls back uncommitted changes. Counts report work in that transaction, so a created parent can also be removed at a later tier in the same call. Same-time reruns do no promotion/expiry work. A backward clock cannot reopen finest-tier ingestion. Late input never goes directly into a coarse bucket, even if its grace is longer.

Query plans chronological disjoint ownership bands: tier 0 [F0,infinity), intermediate i [Fi,F(i-1)), final [Ffinal,F(final-1)); one-tier streams use [F0,infinity). It intersects retained ownership with recorder coverage and filters declared dimensions, never double counting children and parents. resolutions reports actual coverage segments/tier/width; resolution_seconds is the maximum present width or zero with no available history. Query boundaries must not cut an intersecting retained bucket, including empty coarsened intervals or filters matching no groups. Aligned initial/current buckets can have explicitly reported partial recorder coverage.

Original coverage_start stays separate from expired-through. Gaps distinguish not_collected, expired and not_observed_yet. Retained empty count/sum are zero; absent/expired-only statistics are null. Partial availability returns only available state and complete=false. A wholly expired sketch-enabled request reports availability=expired. Advance extends existing recorder coverage but does not invent a collection start before the first batch. Coverage describes the recorder, not upstream feed completeness.

One Advance transaction may lock the handle for a large backlog; context cancellation is supported, but waiting for the Go mutex is not context-aware. There is no work pagination or background scheduler yet. SQLite deletion reuses pages rather than guaranteeing immediate main-file shrinkage. Snapshot produces compact retained state. WAL, synchronous FULL, one serialized connection and modernc.org/sqlite v1.60.1/libc v1.77.1 remain unchanged. Snapshot is VACUUM INTO plus output-file sync; export publication is not atomic and interruption can leave partial output. Copy only successful snapshots.
